A complete story in exactly six words: "Sorry, soldier. Your village is gone." A soldier survives the war and comes home to one flat apology — the home he fought for no longer exists. The program in `main.ts` writes that single line to `/output/entry.txt`, checks it is exactly six words before shipping it, and that text is the whole entry.

## Run it

```sh
node main.ts
```
